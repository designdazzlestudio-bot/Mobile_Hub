# Mobile Hub Website

1. Open `index.html` in a browser.
2. Replace `WHATSAPP_NUMBER` in the script with the real WhatsApp business number in international format, e.g. `923001234567`.
3. Replace placeholder phone/email/location in the Contact section if needed.
4. The site is responsive and includes Home, Shop, About, Contact, product search/filter, Buy Now order modal, delivery calculation, validation and WhatsApp ordering.
